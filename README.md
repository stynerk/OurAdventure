## Product in one line

**어디든 코스를 만들고 → 장소마다 사진으로 개인 스탬프 → 함께 보는 기록 → 리포트·인스타 이미지**

기존 프로토타입은 경주 가족여행용 단일 코스 앱이다(**동화 지도 + 짧은 관찰 Quest + 즉시 스탬프 + 사진 기반 원정기**). v2는 이 경험을 그룹과 임의 여행지로 넓힌다.
