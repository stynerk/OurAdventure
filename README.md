## 2026-10-04 코스 변경

- 상세 일정은 [GYEONGJU_ITINERARY.md](./GYEONGJU_ITINERARY.md)를 따른다.
- 김유신 묘를 금요일의 유일한 주요 방문지로 반영했다. 경주읍성은 선택 방문이다.
- 불국사 주 미션은 극락전 복돼지 동상 쓰다듬기 + 스냅샷이다. 두 탑 비교는 추가 관찰이다.
- 총 8개 미션은 주요 7개(1+3+3)와 선택 경주읍성 1개다. 대릉원은 일요일 첨성대·월정교 앞에 배치했다. 선택 미션을 안 해도 주요 원정 완료를 표시한다. 기존 동상 기록은 이전 코스 기록으로 보존하고 김유신 묘 완료로 전환하지 않는다.
