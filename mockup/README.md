# Our Adventures 실행형 목업

Node.js가 설치된 환경에서 프로젝트 루트에서 실행한다.

```powershell
node mockup/serve.cjs
```

접속: http://127.0.0.1:4173 (종료: Ctrl+C). 설치·외부 API·계정·토큰 없이 실행된다. 서버 없이 `index.html`을 직접 열 수도 있으나 브라우저에 따라 로컬 저장·링크 복사가 제한될 수 있다.

## 체험 순서

1. 체험 로그인 → 우리 가족 탐험대 → 기존 여행 열기 또는 새 그룹 생성.
2. 리더로 새 여행 만들기 → 이름·날짜·장소를 줄마다 입력 → 스탬프 자동 구성.
3. 별칭을 입력해 초대받은 새 멤버로 참여. 초대 링크는 같은 브라우저의 같은 목업 주소에서만 동작한다.
4. 장소 스탬프 선택 → 카메라 촬영/사진 선택 → 선택적 한 줄 느낌 → 저장.
5. 상단 멤버 전환으로 다른 사람의 스탬프가 미완료인지 확인. 같은 장소를 다시 저장하면 본인 사진·느낌을 교체하며 완료는 중복 계산하지 않는다.
6. 함께 남긴 기록 → 여행 결과 → 사진 최대 4장 선택 → 1080×1350 PNG 다운로드 또는 브라우저 인쇄/PDF 저장.
7. 내 그룹으로 돌아가 같은 그룹 안에 두 번째 여행을 생성. 새 여행의 완료 상태는 별도다.

## 체험용 선택과 한계

- 로그인, 초대, 멤버 전환은 모의 동작이다. 실제 사용자 인증·서버 권한·다른 기기 동기화는 없다. 그룹별 리더만 여행 생성·초대 버튼을 제공한다.
- 사진과 기록은 `our-adventures-mockup-v1` localStorage에만 저장한다. 기존 가족 앱 저장 키를 읽거나 수정하지 않는다.
- 기기 사진은 긴 변 최대 1200px의 JPEG로 줄여 저장한다. 보관·용량·해상도의 제품 정책 확정값이 아니다.
- 장소 20개·한 줄 120자·결과물 4장은 체험용 UI 한도다. 사진 교체 시 완료 유지는 목업 동작이며 최종 정책은 미정이다.
- 결과 카드는 템플릿으로 그린 실제 PNG다. AI 이미지 생성·자동 코스 추천은 포함하지 않는다.
- 목업 데이터 초기화는 하단 버튼에서 명시적으로 확인한 뒤 실행한다.

검증: `node mockup/verify.cjs`. JavaScript 구문 및 모의 DOM 기반 핵심 흐름 검증이며 실제 브라우저·카메라·모바일·인쇄 검증을 대신하지 않는다.
