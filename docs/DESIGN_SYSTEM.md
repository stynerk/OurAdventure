# 디자인 가이드 v2 — 그룹 스탬프 투어 `/next`

작성일: 2026-10-28 · 담당: PM(Claude) · 구현·이미지 제작: Codex (T14)
기준 시안: [디자인 캔버스](https://claude.ai/artifact/VUigNdfEYiVsU2wzafPGof) "v2 다듬은 화면" 페이지 · 근거: [UX 진단표](UX_AUDIT_V2.md)
2026-10-28 사용자 결정: v2 톤으로 전체 페이지를 진행하고, 첫 화면은 여행의 즐거움을 담은 **전체 커버 이미지**를 배경으로 쓴다. 이미지는 Codex가 만든다.

원칙 세 가지: **깊이감(depth) · 사진이 주인공 · 말랑한 도장(clay)**. 기능은 바꾸지 않고 화면만 바꾼다.

## 1. 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F4F5F7` | 앱 바탕 (흰 카드가 떠 보이게) |
| `--surface` | `#FFFFFF` | 카드·시트·탭 |
| `--ink` | `#111827` | 본문·제목, 보조 주 버튼 배경 |
| `--muted` | `#6B7280` | 보조 글자 (흰 바탕 대비 4.5:1 이상) |
| `--faint` | `#9CA3AF` | 숫자 분모 등 큰 글자 전용 |
| `--line` | `#EEF0F3` | 구분선 (꼭 필요할 때만) |
| `--accent` | `#D9411E` | **행동 버튼 1종**(사진 찍기·도장 받기), 다음 장소 |
| `--accent-soft` | `#FFF1EA` / `#FFEDE7` | 미션 박스, 강조 배경 |
| `--accent-ink` | `#B4381A` | 연한 주황 바탕 위 글자 |

도장·멤버 색(파스텔 바탕 + 진한 면): 주황 `#FFE7DE/#FF8A65`, 파랑 `#E1ECFF/#6FA3F5`, 초록 `#E3F7EE/#3DBB8A`, 보라 `#ECE6FF/#8B74E0`. 장소 순서대로 돌려 쓴다. 색만으로 상태를 구분하지 않는다(완료 = 색 + 체크/도장 글자).

## 2. 글자

- 글꼴: **Pretendard**(SIL OFL, 자체 호스팅 또는 CDN). 도장 안 글자만 **Jua**(Google Fonts, OFL).
- 크기 4단계: 제목 26–28 / 800 · 소제목 18–20 / 800 · 본문 15–16 / 500–700 · 보조 12–13 / 700.
- 제목은 `letter-spacing: -0.02em`. 숫자(2/6 등)는 크게, 분모는 `--faint`로 작게.
- 안내 문장은 화면당 최대 1줄.

## 3. 모양·간격·그림자

- 둥글기: 카드 24 · 버튼 18–20 · 칩 999 · 도장 999 · 작은 썸네일 14.
- 간격: 4의 배수, 화면 좌우 여백 20, 섹션 사이 18–22.
- 그림자 3단계:
  - `--shadow-sm` `0 4px 12px rgba(17,24,39,.05)` — 목록 카드
  - `--shadow-md` `0 10px 26px rgba(17,24,39,.08)` — 큰 카드·사진 카드
  - `--shadow-lg` `0 16px 40px rgba(17,24,39,.16)` — 떠 있는 시트·하단 탭
- 행동 버튼에는 색 그림자 `0 10px 22px rgba(217,65,30,.30)`.
- 카드 안에 카드를 넣지 않는다. 테두리 대신 그림자로 구분한다.

## 4. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 주 버튼 | 높이 56–60, `--accent`, 아이콘 + 글자, 화면당 1개. 보조 주 버튼은 `--ink` |
| 아이콘 버튼 | 44×44, 흰 바탕 + `--shadow-sm`, 둥글기 16 |
| 떠 있는 하단 탭 | 좌우 16·아래 24 여백, 높이 64, 둥글기 22, `--shadow-lg`. 선택 탭은 검정 알약 + 흰 글자 |
| 칩 필터 | 높이 38, 선택 = 검정, 나머지 = 흰 바탕 + `--shadow-sm` (드롭다운 쓰지 않음) |
| 진행률 | 원형 링(카드 오른쪽) 또는 장소 수만큼 칸 나눈 막대 |
| 사진 카드 | 사진 위에 칩(장소명) 겹침, 아래 별칭 아바타 + 한 줄 |
| 시트 | 사진 위로 겹쳐 올라오는 흰 시트, 위 둥글기 28 |
| 파일 선택 | 브라우저 기본 "Choose File"을 보이지 않게 하고, 큰 "사진 찍기" 버튼 + 작은 "앨범" 아이콘 버튼으로 연결 |
| 아이콘 | **Lucide** 선 아이콘 한 세트, 선 2–2.4px. 이모지 금지 |

## 5. 도장 (Claymorphism)

- 완료: 원형 면 + 안쪽 그림자 `inset -4px -6px 0 rgba(0,0,0,.14)`, 하이라이트 `inset 4px 4px 0 rgba(255,255,255,.35)`, 색 그림자, Jua 글씨, 살짝 기울임(−10°~8°).
- 다음 장소: 흰 칸 + `--accent` 테두리(2px) + 점선 원 안 카메라 아이콘.
- 아직: 회색 원 `#F1F2F4` + 숫자, 안쪽 그림자 약하게.
- 도장판 칸: 3열, 칸 둥글기 24, 완료 칸은 해당 파스텔 바탕.

## 6. 움직임

| 동작 | 값 |
|---|---|
| 누름 | `transform: scale(.97)`, 120ms |
| 화면·시트 전환 | 200–300ms, ease-out |
| 도장 획득 | 도장이 1.3배에서 1배로 "쾅" 내려앉음(250ms, 살짝 튕김) + 색종이 0.6초 |
| 다음 장소 핀 | 바깥 고리가 천천히 커졌다 사라짐(2초 반복) |

`prefers-reduced-motion: reduce`이면 튕김·반복·색종이를 끄고 즉시 상태만 바꾼다.

## 7. 화면별 적용 (캔버스 v2 + A+B 전체 화면 기준)

| 화면 | 핵심 |
|---|---|
| 첫 화면(로그인) | **전체 커버 이미지 배경**(8절) + 아래쪽 흰 그라데이션 없이 반투명 어두운 막(scrim) 위 흰 글자 · "Google로 시작하기" 1개 · 초대 안내 1줄 |
| 내 그룹 / 그룹 홈 | 아바타 겹침 · 진행 중 여행 = 큰 사진 카드 + 원형 링 · 지난 여행 = 썸네일 카드 · 하단 고정 "새 여행 만들기"(검정) |
| 새 여행 | 목적지 검색 입력 1개가 주인공 · 추천 장소 목록 · AI 미션 버튼은 보조 |
| 초대 참여 | 커버 이미지 축소판 + 그룹 이름 + 별칭 입력 + 참여 버튼 |
| 지도 탭 | 그림 지도 전체 화면 · 떠 있는 상단 바 · 다음 탐험 카드(사진 썸네일 + 주 버튼) · 떠 있는 하단 탭 |
| 코스 탭 | 일차 묶음 · 장소 줄마다 완료 도장 미니 · 미션 1줄 |
| 스탬프 탭 | 도장판 3×2 · 멤버 진행 카드 3개(나 = 검정) |
| 스탬프 상세 | 위 300px 장소 사진 · 겹친 시트 · 미션 박스 · 한 줄 입력 · 앨범 아이콘 + "사진 찍고 도장 받기" |
| 도장 획득 | 연주황 바탕 · 큰 도장 188px · "도장 쾅!" · 진행 막대 · 방금 사진 + 한 줄 · "다음 장소 보기"(검정) |
| 추억 탭 | 칩 필터 · 큰 사진 카드 + 2열 사진 · 수정·삭제는 카드 메뉴(⋯) 안으로 |
| 여행 관리·리포트·인스타 | 같은 토큰. 리포트의 도장 요약은 5절 도장 미니 버전 |

상단의 "실험 버전" 배지와 매 화면 하단 "기존 경주 가족 탐험 열기"는 설정/프로필 메뉴로 옮긴다.

## 8. 첫 화면 커버 이미지 (Codex 제작)

- 내용: 가족·친구 그룹이 함께 여행하며 도장을 모으는 **즐거운 순간**. 특정 실존 장소·인물·브랜드를 그대로 그리지 않는다. 얼굴은 작게 또는 뒷모습.
- 느낌: 밝은 낮, 따뜻한 빛, 손에 든 스탬프 카드나 지도 같은 소품, 흰 바탕 앱과 어울리는 부드러운 색(주황·하늘·초록 포인트).
- 형식: 세로 9:19.5 비율 기준 1170×2532 이상, WebP(품질 80) + JPEG 대체, 1장 400KB 이하 목표. 아래 40%는 글자가 올라가므로 단순한 영역.
- 접근성: 배경 위 글자는 scrim으로 대비 4.5:1 이상. 이미지는 장식이므로 `alt=""`, 앱 이름은 텍스트로.
- 같은 이미지의 축소판을 초대 참여 화면에 재사용한다.
- 생성 도구·프롬프트·라이선스(상업 사용 가능 여부)를 PR에 기록한다.

## 9. 출시 전 체크 (UI UX Pro Max 체크리스트 반영)

이모지 아이콘 없음 · 누를 수 있는 요소 44px 이상 · 텍스트 대비 4.5:1 · 포커스 표시 · 움직임 줄이기 존중 · 칩·배지 글자 잘림 없음(320·375·390px) · 색만으로 상태 구분 안 함.
