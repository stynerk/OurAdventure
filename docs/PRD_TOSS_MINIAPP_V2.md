## 1. 한 줄 정의

**어디로·언제만 고르면 가족 여행 코스가 날짜별로 짜이고, 그 장소들이 그대로 도장판이 되는 미니앱.**

레퍼런스와의 차이: 레퍼런스는 "일정 짜기"에서 끝나지만, 우리는 **짠 코스가 현장에서 도장 미션이 되고, 끝나면 리포트가 된다.** 계획 → 현장 → 기록이 한 흐름이다.

## 2. 목표와 지표

| 지표 | 목표 |
|---|---|
| 자동 추천으로 코스 확정까지 (첫 화면 → 여행 만들기) | **1분 이내** (중앙값) |
| 자동 추천 초안에서 장소를 그대로 둔 비율 | 60% 이상 (추천 품질) |
| 자동 모드 선택 비율 | 측정 |
| 코스 확정 후 초대 링크 공유 | 70% 이상 |
| 추천 실패(0곳) 비율 | 5% 이하 |

## 3. 사용자 흐름 (리더)

```
① 홈 "어디로 가볼까?"
   [어디로: 목적지] [언제: 날짜]  →  [이 여행 만들기]
   추천 여행지 카드 (탭하면 목적지 채움)
② 시트 "코스는 어떻게 짤까요?"
   ├ 자동으로 짜 주세요 — 날짜별로 대표 코스를 넣어 드려요
   └ 직접 고를게요 — 가고 싶은 곳을 담아 같이 정해요
③ (자동) 옵션
   1. 며칠? (날짜에서 자동 선택, 칩으로 변경: 당일~5박 6일)
   2. 어떤 여행? (복수) 대표 명소 · 체험·놀이 · 자연·산책 · 먹거리 · 느긋하게
   3. 얼마나 걸을까? 조금 / 보통
   + 추천 기준 안내 상자
④ 코스 초안 = 일정표 (일차별 장소, 수정 가능) · [도장 미션 만들기(AI)]
⑤ [여행 만들기] → 초대 시트 (자동 문구 · 토스 공유 / 나중에)
⑥ 여행 지도 탭
```

멤버: 초대 링크 → 토스 로그인 → 별칭 → 일정표 보기 · **가볼 곳**에 후보 담기·👍.

## 4. 기능 요구사항

### R1 홈·추천 여행지

- 첫 화면은 **어디로 · 언제** 카드 2개와 주 버튼 1개.
- 아래에 추천 여행지 카드(사진 + 도시명 + 한 줄 특징). 국내 6 + 해외 3으로 시작하고 운영에서 고친다(데이터로 관리, 코드 수정 없이 변경).
- 목적지 입력은 지도 검색(Places Autocomplete, 도시·지역 단위).
- 카드 사진은 상업 사용 가능한 출처만 쓰고 출처를 "사진 출처" 링크로 밝힌다.

### R2 방식 선택

- 자동 / 직접 두 카드. 마지막 선택을 기억한다.
- 어느 쪽이든 결과는 같은 **코스 초안 화면**(R4)으로 간다.

### R3 자동 코스 추천

추천은 세 단계로 만든다. **장소는 실제 지도 검색 결과에서만** 고르고, AI가 장소를 지어내지 않는다(PRD v2 하이브리드 원칙).

| 단계 | 방법 | 비고 |
|---|---|---|
| 1. 후보 모으기 | 스타일별 검색어·분류로 Places 검색(목적지 반경 내). 국내는 한국관광공사 TourAPI(공공데이터) 관광지 목록을 보조로 합친다 | 평점·리뷰 수·영업 상태로 거른다. 폐업·임시휴업 제외 |
| 2. 고르기 | 스타일 가중치 + 인기(리뷰 수) + 가족 적합(체험·공원·박물관 가점, 술집·클럽 제외) 점수로 일수 × 하루 장소 수만큼 선택 | 먹거리 스타일이 없어도 하루 1곳은 식사 장소를 넣는다 |
| 3. 일차 배분 | 좌표로 가까운 곳끼리 묶고(일수만큼 묶음), 묶음 안은 가까운 순서로 정렬 | 하루 3~4곳(걷기 "조금"이면 2~3곳), 첫날·마지막 날은 2~3곳 |

- 시각은 **10시 출발 기준 추정**: 머무는 시간(분류별 기본값: 명소 60분, 식사 60분, 박물관·체험 90분, 산책 45분) + 이동 시간.
- 추천 기준 안내 상자를 보여준다: "인기 많고 가족이 가기 좋은 곳을 골랐어요. 가까운 곳끼리 같은 날, 하루 3~4곳, 첫날·마지막 날은 가볍게 넣었어요."
- 결과가 부족하면(필요 장소의 절반 미만) 있는 만큼 넣고 "직접 더 담아 보세요" 안내. 0곳이면 직접 고르기로 보낸다.
- 다시 추천: 옵션을 바꿔 다시 만들 수 있다(리더당 하루 10회 제한, 서버 캐시 24시간).
- 레퍼런스처럼 **여행사 상품 일정을 그대로 가져오지 않는다**(저작권·이용약관 위험).

### R4 코스 초안·일정표 (코스 탭과 같은 화면)

- 상단 탭: **가볼 곳 · 일정** (숙소·경비는 제외).
- DAY 칩: DAY n · 날짜 · 장소 수. 선택한 날만 보여준다.
- 일차 카드: 제목(예: "용두암 근처에서 시작하는 하루") · 이동 합계(분·km) · "10시 출발 기준" · **날짜 메모**(선택).
- 장소 줄: 순서 번호 · 예상 시각 · 사진 · 이름 · 분류 · 머무는 시간 · ⋯ 메뉴(다른 날로 옮기기, 순서 바꾸기, 시각·머무는 시간 바꾸기, 빼기).
- 장소 사이: 이동 수단(자동차·대중교통·걷기, 여행 전체 기본값 1개) · 시간 · 거리.
- 여행이 시작된 뒤에는 장소 줄에 **도장 미니**(받음/다음/아직)와 미션 1줄을 함께 보여준다.
- "도장 미션 만들기(AI)"는 확정 전 언제든 누를 수 있고, 실패해도 여행은 만들어진다(PRD v2 AC-2g).

### R5 이동 시간

- 확정 전 초안: **직선거리 기반 추정**(자동차 30km/h, 걷기 4km/h)으로 즉시 표시한다.
- 여행 만들기 후: Google Routes API로 **실제 경로 시간**을 한 번 계산해 저장한다. 장소를 옮기면 바뀐 구간만 다시 계산한다.
- 대중교통 경로가 없는 지역은 자동차로 표시하고 안내한다.

### R6 가볼 곳·함께 고르기 (PICK)

- 가볼 곳 = 아직 일정에 넣지 않은 후보 목록. 리더·멤버 누구나 검색해서 담을 수 있다.
- 멤버는 후보에 👍 할 수 있다(1인 1표, 취소 가능). 👍 수 순으로 정렬.
- **일정에 넣기는 리더만** 한다. 넣으면 그 장소가 모든 멤버의 도장판에 생긴다.
- 자동 추천에서 뺀 장소는 가볼 곳으로 옮겨 둔다(버리지 않음).

### R7 초대 시트

- 여행 만들기 직후 띄운다. "같이 갈 사람을 불러 볼까요?"
- 자동 문구: "{목적지} 같이 가자! {시작일}부터 {N박 M일}, {장소1}·{장소2} 외 {K}곳 발도장 찍으러 가요." 리더가 고칠 수 있다.
- 토스 공유하기로 보낸다. "나중에 할게요"를 둔다.

## 5. 수용 기준

| ID | 수용 기준 |
|---|---|
| AC-R1a | 추천 여행지 카드를 누르면 목적지가 채워지고, 목록은 코드 배포 없이 바꿀 수 있다 |
| AC-R3a | 목적지·날짜·스타일을 고르고 자동을 누르면 **10초 안에** 일차별 초안이 나온다(캐시 없음 기준 P90) |
| AC-R3b | 초안의 모든 장소는 지도 검색 결과에 있는 곳이고, 폐업·임시휴업 장소가 없다 |
| AC-R3c | 일차별 장소 수가 규칙을 따르고, 같은 날 장소끼리 최대 이동이 자동차 기준 40분을 넘지 않는다(넘으면 안내 표시) |
| AC-R3d | 후보가 부족하면 있는 만큼 넣고 안내하며, 0곳이면 직접 고르기로 이동한다 |
| AC-R4a | 장소를 다른 날로 옮기면 두 날의 순서·예상 시각·이동이 다시 계산된다. 이미 받은 도장은 유지된다 |
| AC-R4b | 여행 시작 후 일정표에 각 장소의 도장 상태가 보인다 |
| AC-R5a | 실제 경로 계산 실패 시 추정값을 유지하고 "추정" 표시를 남긴다 |
| AC-R6a | 멤버는 후보 담기·👍만 가능하고, 일정에 넣기·빼기는 리더만 가능하다(서버 규칙으로 막음) |
| AC-R7a | 초대 문구에 이름·별칭이 들어가지 않는다 |

## 6. 데이터

- `trips/{tripId}`: `buildMode`(`auto`·`manual`), `styles`(배열), `pace`(`light`·`normal`), `travelMode`(`car`·`transit`·`walk`), `startTime`(기본 "10:00"), `dayNotes`(일차 → 메모).
- `trips/{tripId}/places/{placeId}`: 기존 필드 + `day`, `order`(일차 안), `plannedTime`, `stayMinutes`, `category`, `source`(`auto`·`search`), `legToNext`(`minutes`, `meters`, `estimated`).
- `trips/{tripId}/candidates/{placeId}`: `addedBy`, `likes`(UID 배열), `fromAuto`.
- 추천 캐시(서버 전용): 목적지·스타일·일수 키, 24시간.
- 기존 여행(일차 없음)은 `day = 1`로 본다.

## 7. 분석 이벤트 (ANALYTICS_SPEC에 추가, `channel: toss`)

`home_destination_card_click`(rank) · `course_mode_select`(mode) · `course_auto_generate`(days, styles_count, pace, place_count, result: success·partial·empty·error, latency_ms) · `course_auto_regenerate` · `course_place_edit`(action: move_day·reorder·remove·add·time) · `candidate_add`(by_role) · `candidate_like` · `candidate_promote` · `invite_sheet_view` · `invite_share`(source). 장소 이름·좌표·메모 본문은 보내지 않는다.
