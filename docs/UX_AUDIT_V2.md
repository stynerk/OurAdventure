# UX 진단표 — 그룹 스탬프 투어 `/next`

작성일: 2026-10-28 · 담당: PM(Claude) · 근거: PR #8·#12·#13·#14 스크린샷(에뮬레이터, 390px)
목적: "AI 느낌"을 걷어내고 **심플하고 쓰기 쉬운** 화면으로 바꾸기 위한 문제 목록과 개선 기준. 시안 선택 후 디자인 시스템 문서로 이어진다.

## 1. 한 줄 진단

**모든 것이 같은 무게의 둥근 카드와 설명 문장으로 싸여 있어서, 지금 무엇을 하면 되는지와 주인공(사진·스탬프)이 보이지 않는다.**

## 3. 화면별 문제

### 그룹·여행 목록 (T3)
- 여행 카드에 그룹 링크·상태 배지·기간·장소 수·안내문이 한 카드에 몰려 있음 → **여행 이름 + 기간 + 진행률 바** 한 줄로, 상태는 배지 하나.
- "새 여행 만들기"가 목록 아래에 묻힘 → 화면 하단 고정 주 버튼(리더만).

### 여행 헤더 (T7)
- 여행 정보가 큰 카드로 화면 1/3을 차지 → **얇은 상단 바**(뒤로 · 여행 이름 · 리더면 "관리" 아이콘).
- "종료된 여행이에요…" 문장 → 상단 바 옆 "종료" 배지로 충분.

### 지도 탭 (T7)
- 그림 지도 아래 설명 문장·"다음 탐험" 버튼이 카드 안에 있음 → 지도를 화면 폭 가득, "다음 탐험"은 지도 위 떠 있는 버튼.
- 핀 이름표가 흰 박스라 지도와 겹쳐 보임 → 핀 아래 짧은 라벨, 완료 핀은 색 채움.
- 종료 여행에도 "다음 탐험"이 보임(PR #14 수정 요청 중).

### 스탬프 탭 (T7)
- "내 스탬프 1/2" 아래 카드형 스탬프 → **진짜 도장처럼 보이는 원형 스탬프 그리드**(완료=색 도장, 미완료=점선 원).
- 멤버별 진행은 카드 목록 대신 **이름 + 작은 진행 점** 한 줄씩.

### 스탬프 상세·사진 찍기 (T8 예정)
- 사진 찍기가 화면의 주인공이어야 함 → 화면 절반 이상을 촬영 영역, 미션은 그 위 2줄 이내.

### 초대 오류 (T6)
- 큰 카드 + 긴 문장 → 아이콘 1개 + 한 줄 제목 + 한 줄 안내 + 버튼 1개.

## 4. 개선 원칙 (시안 공통)

1. **한 화면 한 행동** — 화면마다 주 버튼은 하나.
2. **사진과 스탬프가 주인공** — 텍스트·박스보다 이미지 면적이 크다.
3. **글은 줄이고 숫자·배지로** — 1/2, 종료, 완료.
4. **아이 손가락 기준** — 누르는 영역 48px 이상, 하단 탭 아이콘 + 짧은 글자.
5. **일관된 재료** — 아이콘 1세트, 버튼 3종, 글자 4단계, 둥글기 2단계(12 · 999).
