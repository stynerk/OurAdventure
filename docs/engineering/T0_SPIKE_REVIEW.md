## 1. 최신 인계 확인과 정정

PM이 PRD v2·목업 진행 승인과 T0–T12 순서를 기록했다. 구현 담당의 첫 작업은 T0다. 종료 이력은 T3/T10, 하단 지도·코스·스탬프·추억 4탭은 T7에 포함돼 있다. 현재 운영 앱이 이를 이미 구현했다는 뜻은 아니다.

| 항목 | 기존 실험 | 최신 구현 기준 | 처리 |
|---|---|---|---|
| 장소 출처 | AI가 목적지만 보고 장소 생성 | 지도 검색이 주는 실제 장소·ID·좌표 | 기존 응답은 운영에 연결하지 않음, T4에서 검색 어댑터 구현 |
| AI 출력 | 장소명·추천 이유·이모지 | placeId + 스탬프 이름·질문·관찰·사진 아이디어 | T5에서 전환 |
| 수량 | 일 2~3곳, 전체 20개 실험값 | 일 3~4곳, 전체 최대 10곳 | T4/T5 검증으로 전환 |
| 모델 | 종전 모델 자동 기본값 | 모델·품질·비용 검토 후 선택 | 기본값 제거, OPENAI_MODEL 없으면 호출 거부 |
| 실험 화면 | 개발용 AI 코스 화면 | 기획 담당 목업이 화면 기준 | 스파이크 안내로 명시, 서비스 화면으로 승격하지 않음 |
| 실패 | 설정/호출 오류 안내 | 검색 장소 유지 + 기본 스탬프 문구 | T5에서 모델 재요청 최대 1회 후 대체 |

이번 PR의 범위는 기존 development/ 미커밋 실험 4개 파일의 격리·실험 상태 명시·모델 명시 선택 검사 및 이 보고서다. 루트 앱·사진·사용자 기록·목업·기획 파일을 변경하거나 포함하지 않는다. reference/ JSON과 추출기는 기존 커밋 자료를 참조한다.

## 2. 지도 검색 후보

한국 장소 품질은 실제 응답을 비교하지 않았으며 아래 적합성은 API 기능으로부터의 판단이다. 공급자 선정 전 경주·부산·제주·서울의 같은 검색어로 장소 누락·중복·좌표·응답시간을 비교해야 한다.

| 후보 | 공개 제공량·요금 | 기능상 판단·제약 |
|---|---|---|
| Kakao Local | 키워드 장소 검색 일 100,000건, 전체 API 월 3,000,000건 공유. 무료 적용 앱 조건 존재. 추가 쿼터 키워드 검색 2원/건 | ID·이름·분류·주소·좌표 제공. 한국 우선 서비스의 1차 후보. 지도 SDK 호출과 REST 검색의 한도는 별도 확인 |
| NAVER 지역 검색 | 검색 API 일 25,000회 공유, 결과 최대 5개, start 최대 1 | 국내 후보지만 한 검색어당 결과 폭이 작아 여러 검색 필요. 장기 여행 데이터 보관·AI 전달 조건은 약관 검토가 필요 |
| Google Places Text Search Pro | 월 무료 5,000회, 첫 유료 구간 $32/1,000회 | 해외 확장 후보. 이름 등 요청 필드에 따라 SKU 달라짐. 지도 표시·캐시·보관 조건을 구현 전 확인 |

추천: **국내 1차는 Kakao Local을 비교 실험 후보로 제안**한다. 실제 품질 통과·키 제공·계정 무료 쿼터 적용·약관 확인 후 확정한다. 자동 등록·결제 연결은 하지 않는다.

## 3. AI 모델·비용 비교

온라인 텍스트 요금, 입력/출력 100만 토큰당 USD. 캐시·Batch 할인은 적용하지 않았다. 모델 품질 비교는 아직 실행하지 않았다.

| 모델 | 입력 | 출력 | 1회 예시: 입력 4,000 + 출력 3,000토큰 | 판단 |
|---|---:|---:|---:|---|
| gpt-5.4-mini | $0.75 | $4.50 | $0.0165 | 신규 품질 비교의 우선 후보 |
| gpt-5.4-nano | $0.20 | $1.25 | $0.00455 | 현재 공식 페이지에 Deprecated 표기. 저가 비교값이며 신규 도입 추천에서 제외 |
| gpt-5-mini | $0.25 | $2.00 | $0.007 | 종전 실험 모델. 현재 공식 페이지에 Deprecated 표기, 자동 기본값 제거 |

월 100회 생성 시 mini 약 $1.65, 1,000회 $16.50. 같은 토큰량의 재요청이 매번 1회 발생하면 각각 $3.30/$33.00. 이는 가정값이며 실제 입력·출력·추론 토큰과 재시도율에 따라 달라진다. API의 max_output_tokens와 요청 수 제한도 월 총액 보장을 뜻하지 않는다.

공식 근거: [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [GPT-5.4 nano](https://developers.openai.com/api/docs/models/gpt-5.4-nano), [GPT-5 mini](https://developers.openai.com/api/docs/models/gpt-5-mini).

### 경주 시범 생성·품질 비교 계획

실행 전 필요한 것: 지도 API 선택·접근키, AI 모델 선택·접근키, 소액 유료 호출 승인. 현재 실험 실행 환경의 키 설정·유료 호출은 이번 작업에서 확인/실행하지 않았다.

- 지도 검색으로 확인한 장소를 사용하며 과거 참조 JSON의 legacyPlaceId를 공급자 ID로 위장하지 않는다.
- 지도 검색의 최대 10개 장소와 경주 예시 3~4개를 형식 참고로 전달한다. 실제 사진·소감·완료 이력은 보내지 않는다.
- placeId는 입력 목록 안의 ID만 허용. 이름·질문·관찰·사진 아이디어 길이, 중복·누락·위험 행동·확정 운영정보를 검사한다.
- 유효하지 않은 출력은 최대 1회 재요청, 이후 검색 장소와 기본 문구를 유지한다.
- 통과 기준은 형식 적합률, 금지 문구·위험 행동, 미확인 ID 0개, 한국어 자연스러움, 리더 수정량, 실측 토큰·지연이다.

## 4. Blaze 및 월 비용 시나리오

Blaze는 사용량 기반이다. 신규 Firebase Storage 사용과 운영 Functions 배포 조건을 충족하기 위해 요금제·권한 확인이 필요하다. **Blaze로 전환하거나 결제 수단을 연결하지 않았다.**

견적 계산 가정(제품 한도 아님): 여행당 사진 100장, 압축 후 평균 0.8 MiB, 사진당 10회 전체 다운로드, 전체 보관량을 월말 최대량으로 계산, AI 1회/여행. 이미지 이중본·원본 보존·백업·soft delete·버전 보관·추가 재열람·세금·환율은 포함하지 않았다. 누적 보관 기간이 길면 저장량은 증가한다.

Storage 계산 단가 **$0.03/GiB·월은 계획용 가정**이며 서울 버킷 확정 견적이 아니다. 외부 아시아 전송의 기본 구간 $0.12/GiB를 참고한다. 무료 등급은 지역·청구 계정·상품 조건이 달라 전체에 일괄 차감하지 않는다.

| 월 여행 수 | 저장량 / 이미지 전송량 | 가정 저장비 + 이미지 전송비 | AI mini 예시 | 함수·DB·빌드·운영 예비비(가정) | 합계 시나리오 |
|---|---|---:|---:|---:|---:|
| 10 | 0.781 / 7.813 GiB | $0.96 | $0.165 | $0~3 | 약 $1.13~4.13 |
| 100 | 7.813 / 78.125 GiB | $9.61 | $1.65 | $0~5 | 약 $11.26~16.26 |
| 1,000 | 78.125 / 781.25 GiB | $96.09 | $16.50 | $5~20 | 약 $117.59~132.59 |

예비비는 견적 확보 전 계획값이다. 이 표는 무료 한도 내 청구액 보장이나 요금 상한이 아니다. 지도 검색은 여행당 5회 가정 시 월 50/500/5,000회이며 무료 적용 조건 충족 시 무료 범위에 들어갈 수 있다. 같은 앱의 다른 사용량도 합산해야 한다. Google의 필드·지도·상세 조회 및 Kakao 추가 쿼터 요금은 별도다.

Functions의 공개 무료 구간에는 호출 200만회/월 등이 있지만 2세대는 런타임·리전·동시성·대기 인스턴스·Cloud Run 계산 조건을 따로 대조한다. 무료 호출 수만으로 운영비를 0원으로 계산하지 않는다. 이미지 저장·전송 외 Firestore 읽기/쓰기·사진 Rules 조회·Cloud Build·Artifact Registry·로그·Secret 관리도 포함해 배포 전 견적을 갱신한다.

공식 근거: [Firebase 요금](https://firebase.google.com/pricing), [Storage 요금제 요구](https://firebase.google.com/docs/storage/faqs-storage-changes-announced-sept-2024), [Cloud Storage 저장·작업·전송 요금](https://cloud.google.com/storage/pricing), [Cloud Run 요금](https://cloud.google.com/run/pricing).

## 5. 사용자에게 제안할 선택과 다음 구현

제안: Kakao Local 품질 비교 + gpt-5.4-mini 소량 비교, 초기 파일럿 월 $5 계획 또는 월 100여행 기준 $20 계획을 사용자 검토에 올린다. 이 금액은 USD 계획값이며 서비스 차단 한도가 아니다. 예산 알림만으로 과금이 멈추지 않는다. 실제 앱에서 여행별 사진/바이트 제한·사용자별 AI 요청 제한·동시 실행 제한을 강제하고 배포 리전·보관·삭제/복구 정책을 확정해야 한다. [Cloud Billing 예산·알림](https://docs.cloud.google.com/billing/docs/how-to/budgets).

결정 대기 중에도 T1의 기존 인증·참여 기반 차이 검토는 읽기·로컬 테스트 중심으로 진행할 수 있다. T4의 공급자 연결, T5의 실제 생성, T8/T9의 운영 Storage는 각 결정 이후 진행한다. PR 머지는 MVP 작업 목록 규칙에 따라 사용자 승인 대상으로 남긴다.
