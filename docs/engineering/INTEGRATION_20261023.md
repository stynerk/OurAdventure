# PR #3 기반 통합 — 구현 및 검증 기록

작성: 2026-10-23 (Asia/Seoul). 기준 main `bca3f94d`, 기반 PR #3 `1db524fc`, 검토 PR #4 `365d967b`.

## 변경

- 최신 main의 PRD v1.3·UX·와이어프레임·콘솔 관찰 기록을 유지하며 기존 PR #3에 통합한다. PR #4의 검토 문서도 포함하므로 별도 대체 구현 PR을 만들지 않는다.
- Firebase setup의 add/add 충돌은 관찰 기록 보존과 개발 절차 분리로 해결했다. HANDOFF/QA는 세 방향으로 병합했다.
- createRoom에 uid별 요청 ID·fingerprint·서버 트랜잭션을 적용했다. 재시도·응답 유실 시 같은 방을 반환한다. 초대 token 평문은 저장하지 않으므로 재시도 응답은 token 없이 반환하고 리더가 링크를 재발급한다.
- 생성 요청을 신규 로컬 namespace에 보관한다. 동일 입력 재시도와 새로고침은 같은 ID를 쓰고 저장 실패 시 생성하지 않는다.
- 참여 여행 room ID를 uid별로 기억하고 홈에서 본인 멤버십·방 정보를 서버 재조회한다. 임의 ID·계정 전환·접근 거부로 권한을 우회하지 않는다.
- 초대 요약에 정원 상태를 추가한다. 정원이 차도 기존 구성원은 복귀 가능하며 가입의 최종 판정은 서버가 한다.
- 신규 모듈을 공개 패키징하고 프런트 단위 검사·서버 통합 검사·SDK/브라우저 시나리오를 보강했다.

기존 PR #3의 통과 결과를 새 통합 버전 결과로 승계하지 않는다.

브라우저는 Playwright1.62의 기본 Chromium151 다운로드가 손상되어, 별도 설치한 Chromium141 headless executable을 명시해 실행했다. 프로젝트 의존성은 바꾸지 않았다. 런타임은 Node24.19.0/Java21이며 CI는 지정된 Node22/Java21로 확인한다. 실제 Google 팝업·운영 Firebase·iOS/Android 실기기·실제 기기 지연은 미검증이다. 로컬에는 바이너리 이미지 자산을 내려받지 않았으므로 원래 이미지의 시각적 회귀 통과를 주장하지 않는다. 원격 트리에서는 원래 자산 blob을 그대로 보존한다.
