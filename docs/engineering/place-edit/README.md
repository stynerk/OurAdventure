# T15 검증 자료

단위 37개, 서버 통합 **51개**(Storage11·그룹27·공동방13), 실제 SDK·장소 편집·그룹·사진·추억·종료·리포트/PNG 브라우저 검증 통과. [서버 로그](integration.log) · [최종 브라우저 로그](verification.log) · [30개 뷰포트 지표](audit.json).

서버 전용 3개 프로세스는 모두 성공했다. 함께 실행한 첫 브라우저 검사는 해의 42px/42.000007px 소수점 좌표를 완전히 같은 값으로 비교해 중단됐다. 0.05px 허용 오차로 테스트를 보정한 뒤 브라우저 전체를 별도 실행해 종료 코드0을 확인했다. 최초 테스트 서버의 새 모듈 허용 목록 누락도 수정했다. 기능 실패를 통과로 표시하지 않는다.

지도 해의 원형과 완료 핀/도장의 동일 색상은 실제 브라우저의 크기·계산 색상으로 검사했다. 새 화면 2개 외 기존8개 화면도 같은 3개 폭에서 검사했다. 로그인·그룹·지도·스탬프·상세·획득·추억·리포트의 기존 기능/접근성 검사를 유지한다. 합성 사진·별칭·여행만 사용하며 실제 이용자 데이터·초대 토큰은 캡처에 포함하지 않는다.

사진은 장소 제외 뒤에도 추억에 남는다. 서버는 작성자의 원본 권한을 유지한다. 실제 Storage 다운로드/원본 삭제 권한 검증과 UI의 2명·3장 영향 안내, 취소, 4장으로 바뀐 후 재확인, 빈 장소 즉시 제외, 멤버 도장판 자동 갱신, 요청 응답 유실·새로고침 재시도를 검사했다.

실기기·운영 OAuth/Storage/GA는 후속이다. 보안 규칙·결제·운영 권한을 바꾸거나 머지·배포하지 않았다.
