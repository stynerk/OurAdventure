이 기반은 종전 Room·고정 경주 코스·shared 진행 모델이다. 재사용 Group → Trip → Place·개인 StampCompletion 전환은 T2, 새 여행 빈 상태와 종료 이력 목록은 T3/T10, 하단 4탭은 T7이다. 기반 코드가 존재한다는 이유로 새 제품 기능까지 완료 처리하지 않는다.
