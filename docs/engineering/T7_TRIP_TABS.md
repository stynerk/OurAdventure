# T7 여행 4탭·리더 관리 기반

기준: PRD v2 F7, QA G1/G2/G3의 4탭·권한·읽기 전용 부분. PM 점검 PR #9에서 T7을 다음 순서로 지정한 내용을 반영했다. 브랜치는 `engineering/trip-tabs`, 기준은 T6 PR #12다.

## 동작

- `#trip/{group}/{trip}/{map|course|stamps|memory}`로 직접 진입·새로고침·뒤로 가기를 지원한다. 기본은 지도다. 리더와 멤버가 같은 하단 내비게이션을 사용한다.
- 지도: 앱 안 SVG 그림 지도에 등록 순서대로 장소 핀·점선 경로·본인 완료를 표시한다. 핀과 다음 탐험은 앱 안 스탬프 상세로 이동한다. 실제 지리 좌표를 표현하는 지도가 아님을 안내한다. 지도 API·외부 이미지 요청은 없다. 스탬프 상세의 보조 Google Maps 링크만 유지한다.
- 코스: 여행의 placeIds 순서를 유지하고 장소와 미션 4요소를 표시한다. 생성 미션이 없으면 일반 관찰 문구를 표시한다. AI가 생성한 결과로 표시하지 않는다.
- 스탬프: 현재 인증 UID의 완료만 기본으로 보여준다. 같은 별칭이어도 별도 UID로 계산한다. 멤버별 진행도 같이 읽는다. 여러 사진이나 중복 완료 문서는 장소당 1개로 계산하며 현재 여행에 없는 장소와 사진 0개인 완료는 제외한다.
- 추억: `status == published` 쿼리로만 기록을 읽고 별칭·장소·한 줄을 이스케이프해 표시한다. 사진 objectPath는 표시하지 않는다. 한 번에 최대 50개를 조회하며 전역 최신순·페이지네이션·실제 썸네일은 T9에서 연결한다.
- 진행 중 여행의 리더만 상단 여행 관리 링크를 본다. 관리 화면에서 참여 현황과 그룹 초대 화면으로 이동한다. 종료 여행은 리더에게도 관리 링크를 표시하지 않으며 관리 주소를 직접 열면 읽기 전용 지도를 보여준다. 멤버의 진행 중 여행 관리 경로 직접 접근은 거부한다.
- 종료 여행도 같은 4탭과 상세 화면에서 읽는다. 사진·스탬프 작성 컨트롤은 없다. 사진 저장·종료 액션·리포트·이미지 저장은 각 후속 티켓에서 연결한다.

각 화면은 현재 계정·화면 세대가 일치할 때만 렌더링한다. 그룹·역할을 서버에서 검증한 뒤 여행 하위 데이터를 읽고, 탭 이동·재진입 시 서버 상태를 재조회한다. 실시간 자동 갱신은 후속이다. 루트 경주 앱·기존 저장 키·회원 권한 규칙은 변경하지 않는다.

## 분석 연결

PM Analytics 명세의 `screen_view`를 성공한 화면 렌더링 후에만 호출하는 주입 지점을 추가했다. 지도/코스/스탬프/추억/스탬프 상세의 고정 이름과 역할·그룹/여행 ID·상태만 전달한다. 권한 실패·이전 응답은 보내지 않는다. PR #11의 허용 목록에도 해당 이벤트를 추가했다. T7 브랜치는 PR #12 위이므로 PR #11과 통합하기 전에는 실제 GA 전송기가 연결되지 않는다. 통합·배포 후 실제 수신을 확인해야 한다.

## 검증

- 로컬 `npm test` 22개 통과: UID 분리·중복 제외·잘못된 장소 제외, 그림 지도 핀/순서/이스케이프, 보조 지도 URL 인코딩, 종료 4탭·관리 숨김/직접 경로, 미공개/원본 경로 비노출, 구문·패키징·루트 보존, 이전 응답 차단, 화면 이벤트 순서.
- 실제 SDK + demo Auth/Firestore + exported callable HTTP handler + Chromium 통과: 그룹·여행 생성/복구, 초대·재입장·정원, 리더·멤버 4탭, 개인별 다른 완료, 공개 완료 기록만 조회, 다음 탐험·지도 링크·관리 화면, 로그아웃, 320/390px 헤더·탭 가로 넘침 없음.
- 완료·사진 기록은 신뢰한 관리자 테스트 fixture를 사용했다. 실제 Storage 업로드 테스트는 아니다. SDK 3세션 기존 Room 회귀도 통과했다.
- 화면 검수에서 로컬 Auth 에뮬레이터 경고가 하단 탭을 가리는 문제를 찾아 로컬에서만 탭 위치를 올렸다. 운영 레이아웃에는 적용하지 않으며 경고를 숨기지 않는다.

## 남은 범위

리포트를 포함한 F7 전체 완료나 AC-7a 전체 통과를 주장하지 않는다. 지리 좌표 검색은 T4, 사진 업로드/썸네일은 T8/T9, 종료·리포트는 T10, PNG는 T11이다. 현재 지도 탭은 API 없는 탐험 그림 지도다. 본문 아래에 탭 높이 이상의 별도 여백을 확보했으며 320/390px 최하단 스크롤에서 본문이 탭 위에 보이는지 검사한다. 사진 본문 표시·전역 최신순·페이지네이션도 후속이다. 물리 iOS/Android와 운영 OAuth는 미검증이다.

main 머지·공개 배포·결제·접근 권한 변경은 하지 않았다. 공개 운영 상태와 PM 검토 반영 내역은 [점검 보고서](PM_REVIEW_20261027.md)에 분리했다.
