## 6. 중단 조건과 병행 가능한 작업

- 운영 Functions 배포·요금제·비용 경계는 현재 확인 필요다. Spark 설정 기록을 운영 callable 배포 완료나 과금 승인으로 해석하지 않는다.
- 이 문서는 새 과금, 자동삭제, 보관 기간, 사진 규격·상한을 승인하지 않는다.
- 비용·보관 결정과 독립적인 로컬 통합, 멱등성·권한 테스트, 명세 정합화는 계속 진행한다.
- 1A는 가족·지인 리더 포함 최대10명. 30명은 후속 검증, 학교 제출은1C, 코스 제작은 Phase2다.
- 모든 BASE/LIVE 판정에는 실제 실행 결과가 필요하다. 기존 CI 성공과 원격 정적 검토만으로 PASS를 채우지 않는다.
