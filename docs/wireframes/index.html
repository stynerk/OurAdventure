이번 검토에서 볼 것

확정 범위

가족·지인 최대 10명(리더 포함), 리더 1명, 여행·활동 1건. 공동 게시판과 리더의 일기·앨범 출력. 기존 경주 9개 Quest와 4탭을 유지합니다.

정책·구현 미결정

사진 용량·장수·보관 기간·예산·저장소·오프라인 열람·출력 기록 한도는 미확정입니다. 샘플의 글·사진·선택 수는 정책 한도가 아닙니다. 캐시는 영구 보관함이 아닙니다.

프로토타입과 실제 제품

이 파일의 행동은 메모리 안의 시뮬레이션입니다. 새로고침하면 사라집니다. 서버 저장·자동 전송·실제 구성원 동기화·운영 데이터 변경을 하지 않습니다. 브라우저 인쇄는 회색 이미지 모형만 출력합니다.

컴포넌트 참고

Component Gallery의 Tabs·Accordion 패턴을 참고했습니다. 주요 기능은 button, 탐색은 명시적 탭, 검토 메모는 details/summary를 사용합니다.
